你是一个顶级量化策略研究员，专精A股ETF轮动策略设计。

你的任务是设计一个ETF交易策略函数，目标是：
- 年化收益率 ≥ 25%
- 最大回撤 ≤ 15%
- 在2019-2024年每个单独年份都尽量盈利（6折交叉验证）

## 策略环境

### 可交易标的
A股ETF（约20-25只高流动性ETF），包括：
- 宽基：沪深300/中证500/上证50/创业板/科创50
- 行业：银行/证券/消费/医药/半导体/新能源/军工/煤炭/有色/地产
- 红利：中证红利/红利低波
- 其他：新能源车/光伏等

### 可用数据列（每只ETF的DataFrame，最近300个交易日）
量价数据：open, high, low, close, vol, amount, pct_chg
份额数据：fd_share（基金份额万份）, share_chg（日份额变动）, share_chg_pct（份额变动率）
复权价：close_adj, open_adj, high_adj, low_adj
收益率：returns_1d, returns_5d, returns_10d, returns_20d, returns_60d
波动率：volatility_20d, volatility_60d
动量：momentum_5d, momentum_20d, momentum_60d
均线：ma5, ma10, ma20, ma60, ma5_bias, ma10_bias, ma20_bias, ma60_bias
量能：vol_ma5, vol_ma20, vol_ratio
振幅：amplitude, amplitude_ma5

```python
def compute_strategy(

    entry_prices: Dict[str, float],       # 各持仓入场价格
) -> Dict[str, float]:
    # 返回目标权重向量
```

### 约束
- 最多持有10只ETF
- 权重和 ≤ 1.0（差额为现金）
- 每次交易单边成本 0.1%
- 不能使用未来数据（只能看到截止 current_date 的历史）

### 策略评估
- 6折交叉验证：2019-2024年每年轮流做测试集
- 适应度 = 平均Calmar比率 + 一致性 + 盈利fold占比
- 惩罚：亏损年按亏损幅度线性扣分，回撤超15%额外扣分
- 快速预评估：先跑2022/2023年，回撤>30%直接淘汰

### 关键市场特征（2019-2024年）
- 2019年：普涨，科技+消费领涨
- 2020年：疫情冲击后V型反转，医药/科技暴涨
- 2021年：核心资产崩塌，周期/新能源接力
- 2022年：全面熊市，几乎无处可躲（红利相对抗跌）
- 2023年：结构性机会，AI/中特估主线，其余震荡
- 2024年：大盘回暖，红利+科技双线

## 核心A股特征
- 短期反转效应（5-20日反转在A股很强）
- 红利/低波异象持续有效
- 行业轮动较快，动量半衰期约1-3个月
- ETF份额变动可作为机构资金流向的代理
- 市场有明显的牛熊周期，必须有regime判断来规避系统性下跌
- 波动率飙升是最强的风险预警信号
