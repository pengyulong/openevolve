## 字段说明

### 行情数据（来源: fund_daily）

| 字段 | 类型 | 单位 | 说明 | 策略用途 |
|------|------|------|------|----------|
| `open` | float | 元 | 开盘价 | 日内价格位置、跳空缺口检测 |
| `high` | float | 元 | 最高价 | 突破/阻力位检测、波动率计算 |
| `low` | float | 元 | 最低价 | 支撑位检测、波动率计算 |
| `close` | float | 元 | 收盘价 | **核心价格**：收益率、均线、动量等一切信号的基础 |
| `pre_close` | float | 元 | 昨收价 | 涨跌幅验证、缺口计算 |
| `change` | float | 元 | 涨跌额 | 绝对价格变动 |
| `pct_chg` | float | % | 涨跌幅 | **动量/反转信号**的直接输入 |
| `vol` | float | 手 | 成交量 | 量价关系因子、异常放量检测 |
| `amount` | float | 千元 | 成交额 | **流动性筛选**、资金强度信号 |

### 份额数据（来源: fund_share）

| 字段 | 类型 | 单位 | 说明 | 策略用途 |
|------|------|------|------|----------|
| `fd_share` | float | 万份 | 基金总份额 | ETF规模，份额越大越受机构关注 |
| `share_chg` | float | 万份 | 日度份额变动（计算列） | **资金净流入/流出代理**：份额增加=资金流入=看好 |
| `share_chg_pct` | float | 比率 | 份额变动率（计算列） | 标准化的资金情绪指标，可跨ETF对比 |

**核心价值：** ETF份额变动是追踪机构/国家队资金流向的最佳日频信号。当宽基ETF份额突增（如510300单日份额增长>5%），通常意味着大资金入场（汇金/社保/险资）。

### 复权因子（来源: fund_adj）

| `close_adj` | float | 后复权收盘价（计算列） | **长周期动量/趋势信号应使用复权价** |

## 计算列（数据加载器自动生成）

### 收益率类

| 字段 | 计算方式 | 策略用途 |
|------|----------|----------|
| `returns_1d` | close.pct_change(1) | 日收益率，波动率计算基础 |
| `returns_5d` | close.pct_change(5) | 周收益率，短期动量 |
| `returns_10d` | close.pct_change(10) | 双周收益率 |
| `returns_20d` | close.pct_change(20) | 月收益率，中期动量 |
| `returns_60d` | close.pct_change(60) | 季度收益率，长期趋势 |

### 波动率类

| 字段 | 计算方式 | 策略用途 |
|------|----------|----------|
| `volatility_20d` | returns_1d.rolling(20).std() × √252 | 短期年化波动率，风险控制 |
| `volatility_60d` | returns_1d.rolling(60).std() × √252 | 长期年化波动率，趋势稳定性 |
| `amplitude` | (high - low) / pre_close | 日振幅，市场活跃度 |
| `amplitude_ma5` | amplitude.rolling(5).mean() | 振幅均值，波动率趋势 |

### 动量类

| 字段 | 计算方式 | 策略用途 |
|------|----------|----------|
| `momentum_5d` | close/close.shift(5) - 1 | 周动量 |
| `momentum_20d` | close/close.shift(20) - 1 | 月动量 |
| `momentum_60d` | close/close.shift(60) - 1 | 季度动量 |

### 均线类

| 字段 | 计算方式 | 策略用途 |
|------|----------|----------|
| `ma5` / `ma10` / `ma20` / `ma60` | close.rolling(N).mean() | 趋势方向判断 |
| `ma5_bias` / `ma10_bias` / `ma20_bias` / `ma60_bias` | close/maN - 1 | **乖离率**：偏离越大回归概率越高 |

### 量能类

| 字段 | 计算方式 | 策略用途 |
|------|----------|----------|
| `vol_ma5` | vol.rolling(5).mean() | 短期量能水平 |
| `vol_ma20` | vol.rolling(20).mean() | 中期量能基准 |
| `vol_ratio` | vol / vol_ma20 | **量比**：>2 为异常放量，配合价格方向判断突破真假 |

### 评估标准

```python
fitness = calmar_ratio  # 年化收益 / 最大回撤
constraints:
    - max_drawdown <= 15%
    - 任何单自然年不亏损
    - 月度胜率 >= 55%
```

### LLM 可使用的全部信号维度

1. **量价信号**：OHLCV + 各周期收益率/动量/波动率/均线偏离
2. **资金流信号**：ETF份额变动（日频，机构/国家队代理）
3. **折溢价信号**：ETF市价 vs 净值的偏离
4. **北向资金**：外资每日净流入方向
5. **相对强度**：各ETF vs 对标指数的超额收益
6. **截面排序**：同类ETF之间的横向对比（如行业ETF间的相对动量）

### 数据注意事项

- ETF行情必须用 `fund_daily` 接口（非 `daily`）
- 份额数据偶有缺失，已做 ffill 前向填充
- 部分ETF上市较晚，不同ETF的可用历史长度不同
- 北向资金是全市场指标，无法拆分到具体ETF
- 复权价格用于长周期计算，短周期用原始价格即可
